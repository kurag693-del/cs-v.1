### 📁 Затронутые файлы (точные пути)

### ⚙️ Технические требования
- TypeScript strict: без `any`, с явными интерфейсами `AIProvider`, `GenerateParams`, `StreamChunk`.
- Валидация на границах: Zod для входа (`provider` whitelist), Zod для результата генерации (`hook/body/cta/hashtags`).
- `buildPrompt` должен делать безопасную и полную замену всех `{{variable}}`; при пропуске обязательного плейсхолдера — ошибка валидации.
- Жесткие правила качества: `body >= 300`, итоговая структура обязательна, запрет шаблонных фраз централизованным списком.
- Ошибки через единый формат `{ success, data?, error }`; без утечки секретов и внутренних stack trace в клиент.
- Без внешних Supabase/Google AI вызовов: убрать `@google/generative-ai` из потока выполнения, оставить только провайдерный слой.
- Интеграция с Lucia Auth: операции генерации только для валидного `userId`, полученного из сессии/заголовка.

# 🧠 Промпт-библиотека «Креатив-студия»
## Структура
- `v1_*` — стабильные версии. Не удалять. Депрекейт через переименование в `v1_*_deprecated.md`.
- Все промпты возвращают **валидный JSON**. На клиенте/сервере валидируйте через Zod.
- Переменные `{{...}}` подставляются сервером перед вызовом LLM.
- Для LiteLLM/OpenRouter используйте `response_format: { type: "json_object" }`.

## Как использовать
1. Загрузите нужный промпт в `system` или `developer` роль.
2. Подставьте переменные в `user` сообщение.
3. Валидируйте ответ через соответствующую Zod-схему.
4. Логируйте `input → output → cost → latency` для регрессии.

# Библиотека контент-шаблонов (ниши)

Источники пресетов для генератора:

1. **Сферы по вертикалям** — файлы в **`src/lib/templates/*.json`** (кофейня, салон, IT-стартап, личный бренд, фитнес, e-commerce, онлайн-образование).  
   Каждый файл описывает пакет: описание ниши, `brandVoice`, столпы контента и массив **`templates`** — отдельные сценарии с полем `prompt`, платформой, тоном, хештегами и CTA.

2. **Дополнительные однострочные ниши** без отдельного JSON-пакета — **`prompts/templates/catalog.json`** (например IT B2B, недвижимость). Формат строк каталога см. ниже.

При сборке приложения пакеты из п.1 разворачиваются в плоский список шаблонов с **составным id**: `{packId}__{subId}` (например `coffee-shop__new-menu-item`). Валидация: Zod в `src/lib/templates/sphere-packs.ts` и `src/lib/templates/builtin-templates.ts`.

## Поля записи в `catalog.json`

| Поле | Описание |
|------|-----------|
| `id` | Уникальный slug (латиница, дефисы). Менять осторожно: ломает избранное у пользователей. |
| `name` | Короткое название в UI. |
| `industry` | Подзаголовок карточки. |
| `category` | Одна из: `horeca`, `beauty`, `b2b`, `personal`, `retail`, `fitness`, `education`, `realestate`. |
| `defaultPrompt` | Текст темы по умолчанию (редактируется перед генерацией). |
| `suggestedPlatforms` | Массив из `Instagram`, `Telegram`, `VK`, `TikTok`. |
| `tone` | `brand` \| `humor` \| `formal`. |
| `defaultContentType` | Опционально: `post` \| `story` \| `tips` \| `announcement`. |

После правок запускайте `npm run test` — сработает проверка каталога и развёртки сфер.

## Редактирование сферных JSON

- Добавляйте или правьте сценарии в массиве **`templates`** соответствующего файла.
- Плейсхолдеры вроде `{{topic}}` пользователь подставляет в поле «Тема» вручную перед генерацией.
- Не дублируйте же самую нишу в `catalog.json`, если для неё уже есть файл в `src/lib/templates/`.
